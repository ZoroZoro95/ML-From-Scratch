## 🛠️ Setup & Usage

### 1. Clone the repository
```bash
git clone https://github.com/ZoroZoro95/ML-From-Scratch.git
cd ML-From-Scratch
```

### 2. Install dependencies
```bash
pip install numpy matplotlib
```

### 3. Run the scripts
```bash
python linear_regression.py
python multivariate_linear_regression.py
```
